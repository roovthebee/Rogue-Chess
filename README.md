# Rogue Chess

Rogue Chess is a multiplayer game developed in Unity that takes traditional chess and meshes it
with a card system to allow for dynamic modifications to the gameplay.

## Features

- Online multiplayer chess
- Card-based gameplay and rules modification
- ScriptableObject (data-driven) card and piece system
- Host-authoritative network architecture
- Modular chess engine
- Temporary tile and piece effects

## Technologies

- Unity 6
- C#
- Netcode for GameObjects
- Unity Multiplayer Services

## Installation

1. Download the latest release from the GitHub repository: https://github.com/roovthebee/Rogue-Chess
2. Extract the ZIP folder.
3. Run RogueChess.exe.

## How to Play

- White gets the first move.
- Select a piece.
- Choose a legal tile to move the piece to.
- Play cards by selecting them from the bottom of the screen.
- Checkmate the opposing King to win.
